# PsycheHealth

## A Web-App for Predicting Mental Illness, Coupled with a Game as a Diagnostic Solution

PsycheHealth is a web application designed to predict mental illnesses using advanced machine learning algorithms. It features an engaging game that serves as a diagnostic tool, helping users assess their mental health while providing valuable insights.

### Key Features

- **Machine Learning Components**: Engineered and implemented robust ML components to analyze user data effectively.
- **Back-End Infrastructure**: Developed using the Flask framework and integrated with an SQLite3 database for data management.
- **Model Optimization**: Achieved a 25% improvement in model accuracy, resulting in an overall accuracy of **91%** and an F1-score of **0.91**.
- **Global Impact**: The project is projected to positively affect over **280 million people** worldwide.
- **Multi-Domain Exploration**: Gained insights from various domains during the project development.

### Tech Stack

- **Backend**: Python, Flask
- **Database**: SQLite3
- **Frontend**: HTML, CSS
- **Game Development**: Unity
